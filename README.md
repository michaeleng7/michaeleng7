# Olá, sou Michael Alves Ribeiro 👋

### Engenheiro de Computação | DevOps, Backend Python & Inteligência Artificial

Engenheiro de Computação focado no desenvolvimento de APIs de alta performance com **FastAPI**, automação de pipelines **CI/CD**, infraestrutura resiliente e integração de soluções com **IA Generativa (RAG / LLMs)** e **Sistemas Embarcados**.

---

### 🚀 Sobre mim & Foco de Atuação

- 🛠️ **DevOps & Infraestrutura:** Experiência prática com Jenkins, Gerrit, Docker, Ansible, Linux e automações de deploy em Python e Shell Script.
- 🧠 **IA Generativa & RAG:** Construção e deploy de sistemas de busca técnica assistida por IA, integração de LLMs (via Open WebUI, Amazon Bedrock, LangChain, LlamaIndex) e mitigação de vulnerabilidades (Prompt Injection).
- 🐍 **Backend & APIs:** Arquiteturas assíncronas em Python (FastAPI), integração com bancos relacionais/vetoriais (PostgreSQL, MongoDB) e pipelines de processamento de dados (Pandas).
- ⚡ **Sistemas Embarcados & IoT:** Firmware multitarefa em C/C++ com FreeRTOS (RP2040/ESP32), protocolos seriais (UART/I2C/SPI/MQTT) e visão computacional (YOLO).
